Security tools:

These tools generate enormous amounts of data thus the need for siem and soar solutions.

Siem centralizes collected data(logs+events) handles them and we get to alert triage by then

Soar are much more advanced. Although they have same collectors(orchestration) they allow for automation and even security responses to low level threats.

socs main problem is turning noise(isolated logs) into contextual alerts.

* **MaxMind**, can be used to get geolocation information for DNS and IP addresses  
* **CloudPassage,** can be used to get information about system resources  
* **VirusTotal, PhishTank,** and **Symantec**, can help with URL reputation, file reputation, or file detonation  
* **Remedy, ServiceNow**, are ticket management tools  
* **SSH** or **Windows Remote Management** apps allow us to automate many OS-level actions like blocking IP addresses, terminating processes, and so on.
